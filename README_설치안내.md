# Donghyun Lee — AI-Curated Reading Guide (60 papers)

기존 GitHub Pages 주소와 아이보리·딥그린 디자인을 유지하는 업데이트입니다. **60편 전체 개별 논문 페이지에 ChatGPT 작성 읽기 가이드**가 추가되었고, 홈 화면의 기존 6개 추천 카드가 객관적 질문 중심의 AI 가이드로 교체되었습니다.

## 쉬운 업데이트
1. `Donghyun_Lee_60_Papers_AI_Guide_Update_Only.zip`을 압축 해제합니다.
2. GitHub Desktop에서 `philip0604-eng.github.io` 저장소를 열고 **Repository → Show in Explorer**를 누릅니다.
3. ZIP 안의 모든 파일과 폴더를 저장소 폴더로 복사합니다. 같은 이름은 **덮어쓰기**, 폴더는 **병합**합니다. `pdfs` 폴더 전체를 삭제하면 안 됩니다.
4. GitHub Desktop의 변경 파일 목록에 `index.html`, `assets/css/style.css`, `papers/*.html` 등이 보이는지 확인합니다.
5. **Commit to main → Push origin**을 누릅니다. **Actions** 탭에서 배포 완료 후 브라우저를 `Ctrl+F5`로 새로 고칩니다.

## 안내문 성격
AI-Curated Reading Guide는 ChatGPT가 작성한 연구 탐색용 설명문입니다. **학술적 추천, 동료심사, 독립적인 수리·실증 검증 또는 외부 학자의 추천사가 아닙니다.** 저자의 논문 초록과 원문을 직접 읽어 평가해 주세요.
